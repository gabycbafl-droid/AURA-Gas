# Firmware de AURA-Gas

## Descripción

Esta carpeta contiene los archivos del programa que se ejecuta en el ESP32 para controlar el prototipo AURA-Gas.

## Funciones principales

- Leer los datos del sensor MQ-2.
- Comparar las lecturas con el umbral configurado.
- Activar las señales luminosas y sonoras de alerta.
- Controlar el servomotor SG90 para realizar un movimiento demostrativo.

## Herramientas

- Arduino IDE.
- Placa ESP32.
- Librerías necesarias según el código del proyecto.

## Instalación

1. Abrir el archivo del programa en Arduino IDE.
2. Seleccionar la placa ESP32 correspondiente.
3. Elegir el puerto correcto.
4. Compilar el programa y cargarlo a la placa.
